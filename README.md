# 🏡 Virtual Pet Simulator

A fun, interactive **Virtual Pet Simulator** built with **Python** and **Streamlit**.  
Feed, play, and care for multiple pets while monitoring their **happiness**, **hunger**, and **health**. Includes **random events**, **ambient sounds**, and **dynamic backgrounds**!

---

## 🐾 Features

- Create and name multiple pets.
- Choose from various animals: Dog, Cat, Rabbit, Bird, Fish, Hamster.
- Feed, play, give toys, and medicine to your pets.
- Track **happiness**, **hunger**, and **health** with dynamic progress bars.
- Random events affect your pet's stats (e.g., finding a snack, getting sick).
- Automatic stat changes over time.
- Dynamic backgrounds and optional pet images.
- Local ambient sounds for each pet type.
- Game-over conditions if a pet becomes too hungry, sad, or sick.
- Confetti animation when happiness is maxed out.

# 📝 Notes

-Keep your images/ and sounds/ folders organized with correct file names.
-Streamlit version ≥ 1.26 recommended for st.toast().
-All sounds should be local .mp3 files in the sounds/ folder.
